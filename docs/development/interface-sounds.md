# Звуки интерфейса

Три набора: `tok-tak` (по умолчанию), `wood-low`, `velvet`. В каждом 11 сигналов. «Дерево ниже» совпадает с пониженной версией из прослушивания; «Бархат» и «Ток-так» сохранены с теми же тембрами и рисунками.

Готовые Ogg Opus находятся в `client/src/renderer/assets/sounds/`. Список наборов и событий в `client/src/sounds.ts` используется и проигрывателем, и разрешённым списком файлов Electron IPC. Загрузка и декодирование выбранного набора выполняются заранее. Воспроизведение использует выбранное устройство вывода; уровень и выключатель общие для сигналов, отдельно от голоса и трансляций.

Исходный синтез сохранён в `client/scripts/sounds/`. Для пересоздания файлов нужны зависимости клиента, установленный Chromium Playwright и FFmpeg с `libopus`:

```sh
cd client
node scripts/sounds/generate.mjs
```

Обычная сборка использует готовые файлы и не требует FFmpeg или запуска синтеза. Файлы — моно, 48 кГц, Opus 96 кбит/с VBR. В звонке хранится один полный цикл с паузой: 2,2 секунды для «Ток-так», 3,2 для «Дерева ниже», 2,4 для «Бархата». Буфер повторяется до ответа, отклонения или отмены; при остановке остаётся короткое затухание.

Настройки `soundTheme`, `soundVolume` и `sounds` сохраняются в `tolktak.voice`. Старые настройки без набора и неизвестное название получают `tok-tak`; прежний выбор выключателя и громкости сохраняется.

Уведомления ОС создаются без системного звука. Сигнал сообщения использует тот же набор и регулятор; условия показа сообщений и уведомлений сохранены. Сигнал звонка управляется окном входящего вызова. Это предотвращает одновременное воспроизведение системного сигнала и мелодии приложения.
