# Управление сервером

Первый зарегистрированный аккаунт становится администратором. Создайте его сразу после запуска, прежде чем делиться адресом.

## Регистрация и приглашения

Режим определяется через `TOLKTAK_REGISTRATION`:

| Значение | Поведение |
|---|---|
| `invite` | Нужен код приглашения; режим по умолчанию |
| `open` | Зарегистрироваться может любой, кто знает адрес |
| `closed` | Новые регистрации закрыты |

Администратор управляет кодами на странице `/admin` своего сервера. У кода есть срок действия в днях и лимит от 1 до 1000 использований. Удаление кода отменяет приглашение, но не удаляет уже созданные аккаунты.

Ссылка `/?invite=CODE` подставляет код в форму регистрации. Регистрация происходит на сайте сервера; затем пользователь входит в приложение.

## Группы и роли

Администратор сервера управляет приглашениями, но не получает автоматически роль владельца каждой группы. Любой пользователь может создать группу и стать её владельцем.

| Действие | Участник | Модератор | Владелец |
|---|:---:|:---:|:---:|
| Переписка, звонки, демонстрация | Да | Да | Да |
| Изменение имени, изображения и описания группы | | Да | Да |
| Добавление и удаление участников | | Да | Да |
| Создание и удаление каналов и комнат | | Да | Да |
| Назначение и снятие модераторов | | | Да |
| Удаление группы | | | Да |

Когда владелец выходит, группа переходит к участнику, который вступил раньше остальных. Когда уходит последний участник, группа удаляется.

Лимиты группы: 200 участников, 20 голосовых комнат и 30 текстовых каналов. Сообщение — до 4000 символов и до 10 вложений.

## Ограничения текущей версии

Серверного бана и удаления аккаунта пока нет. Удаление человека из групп ограничивает доступ к этим группам, но не отзывает его аккаунт и активные сессии. Не считайте это полноценной блокировкой пользователя.

## Данные участников

Сообщите участникам, как устроено хранение:

- Владелец сервера имеет доступ к базе, переписке, файлам и списку аккаунтов. Сквозного шифрования нет.
- Голос и видео сервером не записываются и не сохраняются.
- Файл доступен любому, у кого есть его случайная ссылка; вход для скачивания не требуется.
- Удаление сообщения убирает текст и список вложений из базы. Сами загруженные файлы остаются на диске.

Подробности — в [модели безопасности](../development/architecture.md).

## Имя и адрес сервера

Имя задаётся через `TOLKTAK_SERVER_NAME`. При смене домена участникам придётся войти заново с новым адресом. На время перехода оставьте старое имя рабочим или настройте перенаправление.
