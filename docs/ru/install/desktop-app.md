# Приложение

## Установка

| Система | Сборка |
|---|---|
| Windows 10 и 11, x64 | `.exe` |
| macOS, Apple Silicon или Intel | `.dmg` для своего процессора |
| Linux, x64 | `.AppImage` или `.deb` |

[Скачать приложение](https://tolktak.d4enst.ru/download/)

Приложение для macOS не заверено Apple, поэтому при первом запуске macOS его блокирует. Нужно открыть «Системные настройки» → «Конфиденциальность и безопасность», найти сообщение о TolkTak и нажать «Все равно открыть». После скачивания новой версии это нужно повторить.

## Регистрация и вход

1. Открыть адрес сервера в браузере и создать учётную запись. Если регистрация работает по приглашениям, понадобится код от владельца.
2. Запустить TolkTak и указать тот же адрес сервера, логин и пароль.

Кнопка регистрации в приложении открывает страницу выбранного сервера в браузере. Учётные записи создаются отдельно на каждом сервере.

Примеры адресов:

- `https://talk.example.com` — сервер с HTTPS;
- `http://192.168.1.20:8080` — сервер в локальной сети без HTTPS.

Вместо примеров нужен адрес своего сервера. Для [самоподписанного сертификата](../guides/certificates.md) также потребуется настройка доверия на устройстве.

## Разрешения

Приложение запрашивает доступ к микрофону и камере при первом использовании. Если доступ запрещён, в настройках голоса и видео появляется предупреждение со ссылкой на системные разрешения.

На macOS для демонстрации экрана нужно отдельное разрешение в разделе «Конфиденциальность и безопасность». После его изменения может потребоваться перезапуск TolkTak.

## Ограничения, связанные с системой

На данный момент у ранней версии есть ограничения, которые зависят от системы. Их планируется устранить в следующих версиях.

- **macOS и Linux:** демонстрация экрана передаётся без звука, а push-to-talk срабатывает, только когда окно TolkTak активно.
- **Windows 10:** при демонстрации передаётся весь звук системы, вместе с голосами участников звонка. Перед началом трансляции приложение предупреждает об этом.
- **Linux с Wayland:** работа глобальных горячих клавиш зависит от окружения рабочего стола.

## Обновления

Приложение следует за версией своего сервера. При запуске небольшое окно спрашивает сервер, какая версия на нём стоит, скачивает её и устанавливает без окна установщика. Если сервер недоступен, приложение запускается как есть. Если сервер обновился, пока приложение открыто, новая версия скачивается в фоне и приложение предлагает перезапуск; если сервер больше не поддерживает текущую версию, обновление ставится сразу.

Так обновляются установщик для Windows и AppImage для Linux. На macOS, в портативном zip для Windows и в пакете `.deb` вместо установки приложение показывает кнопку «Скачать»; новые версии есть в [разделе загрузок](https://tolktak.d4enst.ru/download/).

Проблемы со входом, звуком и трансляциями разобраны в разделе [«Решение проблем»](../operations/troubleshooting.md).
