# Установка через Docker

Docker Compose запускает сервер TolkTak и LiveKit для голоса, видео и трансляций. Инструкция рассчитана на Linux-сервер с установленными Git, Docker и плагином Compose. Оборудование и сетевые порты описаны в [требованиях](requirements.md).

## 1. Файлы проекта

```sh
git clone https://github.com/D4eNst/tolktak.git
cd tolktak/deploy
```

Все дальнейшие команды выполняются из каталога `deploy/`.

## 2. Конфигурация

Скрипт `init.sh` создаёт `.env` с параметрами сервера и `livekit.yaml` с настройками LiveKit. Ключи генерируются при запуске скрипта. Эти файлы содержат секреты и не предназначены для публикации.

### Сервер в интернете

Для HTTPS нужны [два доменных имени](../guides/domains.md), направленных на сервер: одно для TolkTak, другое для LiveKit.

```sh
./init.sh talk.example.com lk.example.com
```

Вместо примеров используются свои домены. В этой конфигурации сервисы слушают `127.0.0.1`; HTTPS обеспечивает [обратный прокси](../guides/reverse-proxy.md) с [сертификатами](../guides/certificates.md) для обоих имён. Для звонков также нужны открытые [медиапорты](../guides/firewall.md).

### Сервер в локальной сети

Для запуска без HTTPS скрипту передаётся доступный участникам адрес машины:

```sh
./init.sh --http 192.168.1.20
```

При таком адресе TolkTak будет доступен на `http://192.168.1.20:8080`, LiveKit — на `ws://192.168.1.20:7880`. Пароли, сообщения и файлы передаются по HTTP без шифрования. Для сервера в интернете предусмотрен вариант с HTTPS выше.

### Параметры сервера

В `.env` находятся основные настройки:

| Параметр | Назначение |
|---|---|
| `TOLKTAK_SERVER_NAME` | Название сервера. |
| `TOLKTAK_REGISTRATION` | Режим регистрации. По умолчанию `invite` — по приглашениям. Первый аккаунт можно создать при любом режиме. |
| `TOLKTAK_VERSION` | Версия образа TolkTak. По умолчанию `latest`; конкретный тег позволяет закрепить версию. |

Остальные параметры описаны в [справочнике конфигурации](../operations/configuration.md). Если `.env` уже существует, `init.sh` остановится, чтобы не перезаписать конфигурацию. Изменения в существующие файлы вносятся вручную.

## 3. Запуск

```sh
docker compose up -d
docker compose ps
```

Compose скачивает образ `ghcr.io/d4enst/tolktak-server` с выбранным тегом и запускает оба сервиса. Их журналы доступны командой:

```sh
docker compose logs --tail 100 tolktak livekit
```

## 4. Первый аккаунт

После запуска нужна регистрация по адресу сервера: например, `https://talk.example.com` или `http://192.168.1.20:8080`. **Первый аккаунт становится администратором**, поэтому его стоит создать сразу.

Панель управления доступна по пути `/admin` на том же адресе. Там создаются приглашения для остальных участников. Они регистрируются на странице сервера и входят в [приложение](desktop-app.md) с тем же адресом, логином и паролем.

## 5. Проверка подключения

Проверка включает вход с двух аккаунтов, обмен сообщениями, звонок и демонстрацию экрана. Подключение участника из другой сети позволит проверить доступность медиапортов: работающий чат сам по себе этого не подтверждает.

Если голос или видео не подключаются, причины и команды проверки собраны в [разделе диагностики](../operations/troubleshooting.md). После первого запуска стоит настроить [резервное копирование](../operations/maintenance.md).
