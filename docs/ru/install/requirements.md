# Требования

## Сервер

- Linux на x86-64 или ARM64;
- Docker Engine, а для [установки через Docker Compose](compose.md) ещё и плагин Compose версии 2.23.1 или новее;
- доступ к настройкам сети и файрвола;
- место для базы, загруженных файлов и резервных копий.

Запустить TolkTak в Docker можно двумя способами:

| Вариант | Что запускается | Когда подходит |
|---|---|---|
| [`docker run`](docker.md) | Один контейнер с TolkTak и LiveKit, SQLite и файлы в томе, обычный HTTP | Проба, локальная сеть, небольшой сервер за своим обратным прокси |
| [Docker Compose](compose.md) | TolkTak, LiveKit, PostgreSQL, хранилище S3 Garage и Caddy для HTTPS | Постоянный сервер на своём домене |

Для [установки из исходников](source.md) вместо Docker нужны Python 3.14, uv и программа LiveKit Server.

## Нагрузка

Расход памяти, процессора и канала зависит от числа одновременных подключений и медиапотоков. Минимальные требования к процессору и памяти пока не определены.

LiveKit пересылает потоки участникам. Если пять человек смотрят одну демонстрацию экрана, сервер получает один поток и отправляет пять копий. При выборе подключения важна исходящая скорость сервера.

## Адреса

| Вариант | Адреса и связность |
|---|---|
| Сервер в интернете с HTTPS | Одно доменное имя, публичный IP или проброс портов и сертификат (в установке через Compose его автоматически получает Caddy). |
| Локальная сеть без HTTPS | IP-адрес или имя, доступные участникам. |

Настройка описана в инструкции [о доменах и адресах](../guides/domains.md). В режиме HTTP пароли, сообщения и файлы передаются без шифрования.

## Порты

| Порт | Протокол | Назначение |
|---|---|---|
| 80, 443 | TCP | HTTPS и выпуск сертификата в установке через Compose или со своим обратным прокси |
| 443 | UDP | HTTP/3 в установке через Compose |
| 8080, 7880 | TCP | Прямой доступ к TolkTak и LiveKit при `docker run` без HTTPS |
| 7881 | TCP | Звонки, если UDP недоступен |
| 7882 | UDP | Голос, видео и демонстрация экрана |

Порты 7881 и 7882 нужны для звонков при любом варианте: одного порта 443 недостаточно. Примеры правил — в [инструкции по портам](../guides/firewall.md).
