# Требования

## Сервер

Для установки через Docker нужны:

- Linux на x86-64 или ARM64;
- Git, Docker Engine и плагин Compose;
- доступ к настройкам сети и файрвола;
- место для базы данных, загруженных файлов и резервных копий.

В стандартной конфигурации используются два сервиса: TolkTak и LiveKit. База SQLite встроена; [PostgreSQL](../guides/postgres.md) подключается отдельно.

Для [запуска из исходников](source.md) вместо Docker нужны Python 3.14, uv и LiveKit Server. Версии и порядок установки приведены в этой инструкции.

## Нагрузка

Расход памяти, процессора и трафика зависит от числа одновременных подключений и медиапотоков. Подтверждённых минимальных требований по CPU и RAM пока нет.

LiveKit пересылает потоки участникам. Если одну трансляцию смотрят пять человек, сервер получает один поток и отправляет пять копий. При выборе канала связи имеет значение и исходящая скорость сервера.

## Адреса

| Размещение | Адреса и подключение |
|---|---|
| Через интернет с HTTPS | Два доменных имени, публичный IP или проброс портов, обратный прокси и сертификаты. |
| В локальной сети без HTTPS | Доступный участникам IP или имя машины. Сервисы работают на отдельных портах. |

Подготовка адресов описана в разделе [«Домены и адреса»](../guides/domains.md). В режиме HTTP пароли, сообщения и файлы передаются без шифрования.

## Порты

Значения по умолчанию из конфигурации проекта:

| Порт | Протокол | Назначение |
|---|---|---|
| 443 | TCP | HTTPS через обратный прокси |
| 80 | TCP | Получение сертификата через HTTP-01, если выбран этот способ |
| 8080, 7880 | TCP | Прямое подключение к TolkTak и LiveKit в режиме HTTP |
| 7881 | TCP | Медиа для подключений, которым недоступен UDP |
| 50000–60000 | UDP | Голос, видео и трансляции |
| 3478 | UDP | TURN |
| 30000–40000 | UDP | TURN relay |

При HTTPS порты 8080 и 7880 доступны только на `127.0.0.1`. Медиапорты LiveKit открываются отдельно: одного порта 443 для звонков недостаточно. Примеры правил и изменение диапазонов — в разделе [«Файрвол и порты»](../guides/firewall.md).
