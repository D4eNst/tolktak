Self-hosting#

TolkTak can run on your own hardware or a rented server.

  • Requirements
  • Install with Docker
  • Install from source

Configuration and maintenance#

  • Configuration — environment variables and LiveKit settings.
  • Administration — registration, invites and access.
  • Upgrades and backups — saving and restoring data.
  • Troubleshooting — connections, audio and service logs.

TolkTak is in early development. Back up server data before upgrading. There is no end-to-end encryption yet: the server operator has access to stored messages and files. See the security model for details.
