Регистрация и вход#

  1. Открыть адрес сервера в браузере и создать учётную запись. Если регистрация работает по приглашениям, понадобится код от владельца.
  2. Запустить TolkTak и указать тот же адрес сервера, логин и пароль.

Кнопка регистрации в приложении открывает страницу выбранного сервера в браузере. Учётные записи создаются отдельно на каждом сервере.

Примеры адресов:

  • https://talk.example.com — сервер с HTTPS;
  • http://192.168.1.20:8080 — сервер в локальной сети без HTTPS.

Вместо примеров нужен адрес своего сервера. Для самоподписанного сертификата также потребуется настройка доверия на устройстве.

Разрешения#

Приложение запрашивает доступ к микрофону и камере при первом использовании. Если доступ запрещён, в настройках голоса и видео появляется предупреждение со ссылкой на системные разрешения.

На macOS для демонстрации экрана нужно отдельное разрешение в разделе «Конфиденциальность и безопасность». После его изменения может потребоваться перезапуск TolkTak.

Различия между системами#

Система Звук при демонстрации экрана
Windows 11 Звук выбранного приложения при демонстрации окна. При демонстрации всего экрана голоса участников исключаются из системного звука.
Windows 10 Весь системный звук, включая голоса участников звонка. Перед трансляцией приложение показывает предупреждение.
macOS и Linux Демонстрация видео без звука.

Push-to-talk вне окна TolkTak работает на Windows. На macOS и Linux для него нужен фокус на окне приложения. Работа глобальных горячих клавиш на Linux с Wayland зависит от окружения рабочего стола.

Обновления#

Новые версии доступны в разделе загрузок. В сборках с автоматическим обновлением приложение скачивает новую версию и предлагает перезапуск. На macOS автоматическое обновление пока недоступно: новая версия устанавливается вручную.

Проблемы со входом, звуком и трансляциями разобраны в разделе «Решение проблем».
