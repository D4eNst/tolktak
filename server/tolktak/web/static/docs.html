Using this server

How to join this TolkTak server, and where its owner finds the full documentation.

Join

  1. Get the desktop app for Windows, macOS or Linux from the releases page or the link on the home page.
  2. Create an account on the home page. If the server asks for an invite code, get one from the server's administrator. An invite link fills the code in for you.
  3. In the app, enter this server's address, , and sign in.

Good to know

  • On macOS, allow the microphone, camera and Screen & System Audio Recording in System Settings the first time you use them.
  • The app updates itself on Windows and Linux. On macOS, download new versions from the releases page.
  • Sharing an application's sound with your screen works on Windows 11. On macOS and Linux the screen is shared without sound.
  • Whoever runs this server can read the messages and files stored on it. Voice and video are not recorded.

Running the server

About TolkTak

TolkTak is free and open-source software under the AGPL-3.0 license. Source code, releases and issues are on GitHub; the project's website is tolktak.d4enst.ru.

Как пользоваться сервером

Как подключиться к этому серверу TolkTak и где владельцу найти полную документацию.

Подключение

  1. Скачайте приложение для Windows, macOS или Linux на странице релизов или по ссылке на главной странице.
  2. Зарегистрируйтесь на главной странице. Если сервер просит код приглашения, получите его у администратора сервера. Ссылка-приглашение подставит код сама.
  3. В приложении укажите адрес этого сервера, , и войдите.

Полезно знать

  • На macOS при первом использовании разрешите доступ к микрофону, камере и записи экрана и системного звука в настройках системы.
  • На Windows и Linux приложение обновляется само. На macOS новые версии скачиваются со страницы релизов.
  • Звук приложения при демонстрации экрана передаётся на Windows 11. На macOS и Linux экран показывается без звука.
  • Владелец сервера может читать хранящиеся на нём сообщения и файлы. Голос и видео не записываются.
