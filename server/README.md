# tolktak-server

The TolkTak server: accounts, groups, chat, files and voice room signalling for
a self-hosted TolkTak instance. Built with FastAPI and Tortoise ORM; stores data
in SQLite by default or in PostgreSQL.

See the [documentation](../docs/README.md) for installation and configuration,
and [building](../docs/development/building.md) for development.
